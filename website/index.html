Windows

  1. Run the installer. If Windows warns you, click More info → Run anyway.
  2. Paste your free Google API key in the window that opens.
  3. Select a job post, press Ctrl+Shift+1, then paste with Ctrl+V.

Android

  1. Open the downloaded file. Allow "install unknown apps" when asked.
  2. Open Bidderr and paste your free Google API key.
  3. On a job post, tap the green B bubble. The proposal is copied for you.
Free Google API key: aistudio.google.com/apikey
