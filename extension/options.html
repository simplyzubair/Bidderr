Closer proposal writer

How to use

  1. Open a job on Upwork or PeopleperHour.
  2. Press Alt+Shift+P. Select text first if you want, otherwise the job description is read from the page.
  3. The proposal appears bottom-right and is copied. On the proposal form it's inserted into the cover letter box automatically.
  4. Use Shorter or New angle if needed, then review and press Submit yourself.

Other keys: Alt+Shift+M chat reply to a selected client message, Alt+Shift+I insert the last proposal. Change keys at chrome://extensions/shortcuts. Right-click selected text also works on any site.
